## 오늘 새로 쓴 명령
cat, grep

## 오늘 쓴 옵션
- `-n` : 찾은 줄에 줄 번호를 붙인다
- `-c` : 조건에 맞는 줄 수를 숫자로 보여 준다

## 찾아보고 알게 된 것
grep 은 파일에서 원하는 글자가 들어 있는 줄만 골라 보여 주는 명령이다.
서버 로그는 줄이 수만 줄이라 눈으로 다 볼 수 없어서, 보안 담당자는 grep 으로 로그인 실패 같은 필요한 줄만 빠르게 찾는다.
`-c` 로 실패 줄 수를 세어 보면, 짧은 시간에 실패가 아주 많을 때 비밀번호를 계속 찍어 보는 무차별 대입 공격을 의심할 수 있다.

## 막힌 것
`grep "실패" sample.log` 를 처음 쳤을 때 아무것도 안 나왔다. 같은 단어로 `-c` 를 쓰면 2 가 나왔다.
터미널에서 한글을 칠 때 조합이 덜 끝난 채로 들어가 글자가 달라졌던 것 같다. 다시 천천히 치니 두 줄이 나왔다.
→ grep 은 글자가 하나라도 다르면 찾지 못한다.
